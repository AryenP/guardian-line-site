What it shows

The first builds flagged few of them. On the baseline set the latest build flagged 1 of 18.

On the latest build, 11 of 52 AI callers would have been sent toward the parent. A test setting stopped the ring, so no phone rang.

We will update these numbers as the builds change. Last run November 12, 2026.

What the columns mean

Flagged as AI
An AI score of 0.6 or more.
Not enough to tell
Too little of the call to judge.
Sent toward the parent
The call would have rung the parent. A test setting stopped the ring.
Timing set
Callers built to show one habit each, so easier to spot.
